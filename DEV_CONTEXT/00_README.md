## Maintenance Guidelines

- Update `PROJECT_STATUS.md` after each significant change or season milestone
- Update `BUG_TRACKING.md` when fixing bugs (include root cause, not just fix)
- Update `CODEBASE_MAP.md` when adding new modules or changing algorithms
- Keep entries factual and concise — store conclusions, not session transcripts
