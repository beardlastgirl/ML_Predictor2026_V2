# =============================================================================
# TEAM NAME GLOSSARY — Liga Profesional Argentina
# =============================================================================
#
# PURPOSE
#   Maps every known team name variant to a single canonical/normalized name.
#   The normalized name must match the value in ARG.csv (football-data.co.uk).
#
# FORMAT
#   Variant Name -> NORMALIZED NAME
#   - Lines starting with # are comments (ignored by the parser)
#   - Matching is case-insensitive
#   - Separators supported: -> = :
#
# HOW TO ADD A NEW VARIANT
#   When a [SEASON CHECK] warning appears, or a scraper returns an unrecognized
#   team name, add a line here:
#       New Variant -> NORMALIZED NAME
#   Add a source comment if known (e.g. # futboltotal, FBref, FootyStats)
#   so future maintainers know where the variant came from.
#
# KNOWN PROBLEM SOURCES
#   - football-data.co.uk  : canonical source, drives NORMALIZED names
#   - FBref                : uses full Spanish names, sometimes English
#   - FootyStats           : often truncates or abbreviates inconsistently
#   - Sofascore / Apify    : varies by season and data entry operator
#   - TyC Sports           : short nicknames, changes by writer
#   - futboltotal.futbol   : mix of short/long, Spanish accents sometimes dropped
#   - Partidos.txt (manual): whatever the user types
#
# CHRONIC AMBIGUITY WARNINGS
#   - "Gimnasia" alone is ambiguous: could be LP or Mendoza — always qualify
#   - "Central" alone is ambiguous: could be Rosario Central or Central Córdoba
#   - "Estudiantes" alone is ambiguous: LP or Río Cuarto
#   - "Independiente" alone maps to Independiente (Avellaneda), NOT Rivadavia
#   - Two "San Martín" clubs exist: SJ (San Juan) and T (Tucumán)
#
# Last updated: 2026-07-31
